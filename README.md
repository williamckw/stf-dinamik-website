# STF Dinamik V7 Website

Responsive five-page corporate website: Home, About Us, Services, HMS, Contact.

## Architecture
Static HTML pages, a shared stylesheet, shared lightweight JavaScript, sitemap and robots file. Publish with GitHub Pages on `main` / root.

## Before public launch
Replace typographic placeholder mark with original STF Dinamik logo. Self-host licensed compressed media; verify third-party video link or swap to official product footage. Confirm actual company email, telephone and address, and connect contact form backend. Set canonical and sitemap to final domain if different. Demo figures are illustrative, and roadmap features are labeled.

SEO depends on useful content, site performance, indexing and external authority; metadata alone does not guarantee rankings.
